# Portfolio Website

Next.js app scaffolded with Next `16.2.6`, React `19.2`, TypeScript, and the App Router.

The portfolio content is currently preserved from `source/index.html` and rendered through the app route so it can be iterated on inside Next.js.

## Getting Started

Next.js 16 requires Node.js `20.9.0` or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` after the dev server starts.

If you are using the local Node runtime installed in this project:

```bash
./scripts/use-local-node.sh npm install
./scripts/use-local-node.sh npm run dev
```
